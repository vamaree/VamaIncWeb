Face framing

AI model loads when enabled. It detects face position and size on this device. Different poses remain different.

AI needs an internet connection once to load its model. If loading fails, manual framing stays available. For MP4, face framing uses a single sampled frame; it does not track motion throughout the video.

How to use

1. Add your media.
2. Set rows, columns and gaps.
3. Enable face alignment if needed.
4. Choose automatic logic or enter numbered groups.
5. Test the click, then press Play.
6. Press Generate MP4 to create the animation with sound. View and download the resulting video.
7. Use Stop before editing framing or the matrix.

AI adjusts framing; it does not generate faces or change a person's expression. Stored projects remain in this browser. To reopen the app, keep this HTML file.
